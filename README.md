# reascripts

REAPER scripts by Jon Lloyd ([lloyd.work](https://www.lloyd.work)), distributed through ReaPack.

## Install

In REAPER, choose *Extensions > ReaPack > Import repositories...* and paste:

    https://github.com/jtllo/reascripts/raw/main/index.xml

Then use *Extensions > ReaPack > Browse packages* to install the scripts.

## Scripts

| Script | Category | What it does |
| --- | --- | --- |
| `jl_import_aaf.lua` | Importers | Imports an AAF into the current project: tracks, clips at the AAF's own timecode, embedded or linked audio, fades and crossfades, clip and track gain, pan, and volume and pan automation. Pure Lua; nothing else to install. Tested on Windows with REAPER 7.73, with AAFs from Pro Tools 25.12 and Premiere Pro 26.2.2. |
